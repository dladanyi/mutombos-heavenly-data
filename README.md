# mutombos-heavenly-data

Dashboard that ranks the teams in the Mutombo's Heavenly Block Party fantasy basketball league
across nine stat categories, using the Yahoo Fantasy API. A Flask JSON API (`backend/`) and a
React + Vite frontend (`frontend/`), deployed together on Vercel.

See [docs/](docs/README.md) for architecture, API, deployment, local development and the
decision log.

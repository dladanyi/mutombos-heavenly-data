# All-Play Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an All-Play tab: for a week, every team played against every other team
(average categories won, all-play W–L–T, and a head-to-head grid), plus the same summed over
the current season's completed weeks with a Record and a Luck column.

**Architecture:** A plain-Python `all_play.py` beside `rankings.py` does all scoring. The week
route adds an `all_play` object to each team; a new `/api/allplay/season` endpoint reads every
completed week's stats and scoreboard through the existing cache and sums them. The frontend
adds a third tab that reuses `App`'s week state (shared arrows) and lazily loads the season.

**Tech Stack:** Flask (pytest) and React + Vite + TypeScript (vitest).

**Spec:** `docs/specs/2026-11-16-all-play-design.md`

## Global Constraints

- **Category win:** higher value wins, TO (`higher_is_better=False`) lower wins; equal ties; a
  value beats `None`; two `None`s tie. Values via `rankings.to_number`. Categories from
  `config.CATEGORIES`.
- **Matchup outcome:** W if `cats_won > cats_lost`, L if fewer, T if equal.
- **Avg Cats:** `Σ(cats_won + 0.5 × cats_tied) / opponents`, output rounded to 2 decimals.
- **Win %:** `(W + 0.5 × T) / (W + L + T)`, output rounded to 3 decimals.
- **Rounding only on output.** Place, order and Luck use unrounded values.
- **Week order:** Avg Cats desc, Win % desc, name. **Week place:** 1 + teams with a strictly
  higher Avg Cats.
- **Season order:** Win % desc, Avg Cats desc, name. **Season place:** 1 + teams with a
  strictly higher Win %.
- **Weeks counted:** `start_week … current_week − 1`, plus `current_week` when
  `client.week_state(current_week, current_week) != "current"`.
- **Season Avg Cats:** mean of the team's unrounded weekly Avg Cats over the weeks it appears.
- **Record / Luck:** from each counted week's `MatchupResult`. Record = summed real category
  W–L–T over weeks with a matchup. Luck = mean over those weeks of
  `(real wins + 0.5 × real ties) − that week's unrounded Avg Cats`, 2 decimals, never `-0.0`.
  Both `null` for a team with no matchup in any counted week, and for every team when any
  counted week's scoreboard failed.
- **Season endpoint failures:** a counted week's stats raising `YahooUnavailable` → the
  standard 503 (let it propagate). A scoreboard failure → record/luck `null`, `no-store`.
- **Season headers:** `short`; `none` when stale, `?refresh=1`, or a scoreboard missing.
- **Copy:**
  - tab "All-Play", hash `#allplay`, after "Star Power"
  - week columns `#`, `Team`, `Avg Cats`, `All-Play`, `Win %`, then `Matchup` (live) or `Result`
  - grid title "Head-to-head", caption "Row team's category W–L–T vs each column team"
  - season title "Season All-Play"; caption "Weeks F–L" (or "Week F" when F = L);
    "No completed weeks yet" when `weeks` is 0
  - season columns `#`, `Team`, `All-Play`, `Win %`, `Avg Cats`, `Record`, `Luck`
  - W–L–T as `9–1–0` (en dashes, ties always shown); Win % as `.900`, `1.000`, `.000`;
    Luck as `+0.25`, `−0.75` (U+2212), `0.00`; missing as `–`
  - a week response without `all_play`: "Reload to see all-play numbers"
- **Public repo:** tests use made-up team names; no new fixtures.

## Review Focus

1. **A live week before any games (every value 0 or `None`):** everyone ties every category,
   Avg Cats 4.5 with 9 categories, all T, all place 1, no crash. Test in Task 1.
2. **A team with a bye in a counted week:** it still counts toward all-play totals but is left
   out of Record and Luck; a team with no matchup at all gets `null` for both. Test in Task 3.
3. **A team missing from some weeks:** averaged over the weeks it appears; `weeks` reflects
   that. Test in Task 3.
4. **After the season** (`current_week == end_week`, its state settling or final): the last
   week is counted; in week 1 the endpoint returns `weeks: 0` and no teams. Test in Task 4.
5. **A browser-cached week without `all_play`:** the tab shows "Reload to see all-play numbers"
   instead of crashing; the season part still renders. Test in Task 6.
